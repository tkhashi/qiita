改行なしでは下記のようによく見る書き方ができる。

```sh
$ echo 'Hello World!' >> README.md
```

改行付きでは以下のようにヒアドキュメントとして記述することで追記が可能。

```sh
$ echo << EOF >> README.md # ここまでコマンドとして打つと入力待機状態になるので文字列を入力
# Hi!
Hello world!
EOF # 終了を表す文字列（ここではEOF）を入力

```

### ヒアドキュメント
文字列リテラルをソースコードに埋め込むための方法のこと。
Bash,ZshなどのUNIXコマンドにおいては `<<` を用いて、一時的な標準入力データを作ることが多い。

この `<<` はリダイレクト演算子と言い、右辺の文字列を左辺の標準入力として扱う演算子である。


ヒアドキュメントはUNIXコマンド固有の構文ではない。
https://www.infra-linux.com/menu-linux4/redirect/


ちなみに `<` 一つでは右辺のファイルパスを指定することでそのファイルの中身を標準入力とすることができる。


### おまけ: 変数展開
スクリプト内で `$MY_VAR` のように記述すると変数を展開できる。

```sh
#bin/bash

SHELL=Bash

$ echo << EOF

# Hi!
Hello $SHELL !
EOF

Hello Bash #変数展開される
```

変数展開させないためには終了を表す文字列をシングルクォーテーションで囲む。

```sh
#bin/bash

SHELL=Bash

$ echo << 'EOF'

# Hi!
Hello $SHELL !
EOF

Hello $SHELL #変数展開されない
```
