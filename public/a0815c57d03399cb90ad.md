空白がある列のみ塗りつぶす処理を作りました。
こういうことができます。

# 使い方

1. 適応したいスプレットシートの`ツール > スクリプトエディタ`を選択。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/634043/25e7861f-9e60-4a95-f196-2f2b869b2fb5.png)

2. `ファイルを追加 `を押して適当なファイルを作ったら下記コードをペースト。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/634043/17fe9892-3ed7-a8cf-dfb0-ab3fdfce60d1.png)


3. 必要に応じてコード内変数を変更してください。
    ##### 色
`var color = "#008000"`のあとに[16進数](https://programmercollege.jp/column/1414/#section300)で指定してください。（たぶんRGBでも動くと思いますが確認していません。）色指定はダブルクォーテーション("")で囲んで下さい。
　　##### 何列目まで塗るか
`untilRow = 7` の数字を変えて下さい。塗りつぶしはアクティブセル位置から上に向かって行われるので塗り終わりたい列番目を記入します。
    ##### 何行目まで塗りつぶすか
`lastCol = 100`の数字を変えて下さい。無論数字が大きいと処理が遅くなるのでいい具合にすると良いでしょう。  

4. 判定したい行の最下部にセルを置くか、範囲選択する。その後2の添付画像にある実行を押すと着色されます。

```applescript
function PaintIfBlank() {
  // シートを取得
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var activeRange =  sheet.getActiveRange();

  //色指定
  var color="#ffff00";
  //塗りたい列番
  var untilRow = 7;
  var limit = activeRange.getLastRow() - untilRow + 1;
  for(var i = 0; i < limit ; i++)
  {
    var checkCellRow = activeRange.getLastRow()-i;
    var activeCol = activeRange.getColumn();
    var checkblank = sheet.getRange(checkCellRow, activeCol).isBlank();

    if(checkblank){
      //塗りたい行数
      var lastCol = 100;
      sheet.getRange(checkCellRow, 1 ,1,lastCol).setBackground(color);
   }
  }
}

```
