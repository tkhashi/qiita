iTerm2ではマウスなしでコマンドライン上の文字列をコピペ出来るんですね！
tmuxを使わないとできないと思っていたので感動しましたよ。
![ezgif.com-gif-maker (2).gif](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/634043/2e86f555-491a-ceeb-0fe5-a1131d11815b.gif)

個人的にはホットキーなんかよりよっぽど嬉しい機能です。


# 【通常モード】⌘+Alt+c 
この自由に闊歩できるモード名がどこさがしても見当たらなかったので便宜的に

通常の入力するモード　:入力モード
自由に闊歩できるモード:通常モード
文字を選択出来るモード:選択モード

として説明します。


⌘+Alt+c でコマンドライン内を自由に闊歩出来るようになります。


# 【モード切替】
| コマンド        | モード     |
| --------------- | ---------- |
| ⌘+Alt+C         | 通常モード |
| ⌘+Alt+C         | 入力モード |
| esc or ctrl + [ | 選択モード |
| ⌘+F                | 検索(選択モード)            |

⌘+Alt+C で通常･入力モードを切替られます。
又、.[zshrcをvimキーバインド][2]にしていればhjklやwbでサクサク移動できます。
[2]:https://builder.japan.zdnet.com/os-admin/20372652/

# Tips: ⌘+F
⌘+F　で検索を掛けられるので目的の文字列へ一撃で飛べますね!

というか[iTerm公式ドキュメント][1]にはマウスレスモードとして
⌘+Fで検索すると選択、Tab(Shif+Tab)で選択範囲の拡大が出来る説明がありました。

日本語･英語綯い交ぜの場合や、パスの一部を直感的に拾う場合などは使えそうです。
使いようですね〜
